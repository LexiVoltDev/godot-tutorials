## How to get it

**Download a ZIP:** click the green **Code** button at the top of this page, then **Download ZIP**, and unzip it.

**Or clone it:**

```
git clone https://github.com/LexiVoltDev/godot-tutorials.git
```

## How to open a project

1. Open **Godot** (each folder's README and the table above list the minimum version; everything was tested on 4.8 beta 1).
2. In the Project Manager, click **Import**.
3. Pick the `project.godot` file inside the tutorial folder you want (for example `hit-stop/project.godot`).
4. Hit **Play** (F5).

Each folder's `README.md` has the controls and what to look for.
