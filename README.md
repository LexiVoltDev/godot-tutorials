# Godot Tutorials by Lexi Volt

Hey! This is where the code and example projects from my Godot 4 tutorials live.
Grab them, poke at them, break them, ship them in your games.

Watch the videos on YouTube: **https://www.youtube.com/@LexiVoltDev**

## What's here

One folder per tutorial. Each folder is a complete Godot project you can open and run.

| Tutorial | Folder | What you'll learn |
| --- | --- | --- |
| Hit-Stop | [hit-stop/](hit-stop/) | A reusable HitStop autoload: damage-scaled freeze, flash, camera shake and an audio dip |

More are on the way.

## How to get it

**Download a ZIP:** click the green **Code** button at the top of this page, then **Download ZIP**, and unzip it.

**Or clone it:**

```
git clone https://github.com/LexiVoltDev/godot-tutorials.git
```

## How to open a project

1. Open **Godot 4.4 or newer**.
2. In the Project Manager, click **Import**.
3. Pick the `project.godot` file inside the tutorial folder you want (for example `hit-stop/project.godot`).
4. Hit **Play** (F5).

Each folder has a `SETUP.md` with the controls and what to look for.
